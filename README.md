# 🏎️ 카트라이더 스타일 3D 드리프트 레이싱 (KartRider 3D Drift)

별도의 설치 없이 웹 브라우저(Three.js WebGL)에서 바로 즐길 수 있는 **카트라이더 스타일 3D 드리프트 & 부스터 물리 엔진 레이싱 게임**입니다.

---

## ✨ 주요 구현 기능 (현재 Step 2)

1. **카트라이더 특유의 슬립 앵글(Slip Angle) 드리프트 물리 엔진**
   - 차체가 바라보는 각도(`carHeading`)와 실제 카트가 미끄러져 이동하는 각도(`moveAngle`)를 분리하여 쫀득한 드리프트 코너링 구현
   - 드리프트 도중 반대 방향키를 입력하여 차체 각도를 제어하는 **카운터 스티어링(Counter-Steering)**
2. **순간 부스터 & N2O 부스터 시스템**
   - 드리프트 종료 직후 타이밍에 맞춰 `↑` 키를 입력하면 터지는 **⚡ 순간 부스터 (Instant Boost)**
   - 드리프트 유지 시간과 각도에 비례해 하단 게이지가 충전되며, 100% 달성 시 **🔥 N2O 부스터 아이템** 획득 (최대 2개 슬롯 보유)
3. **본격 서킷 트랙 & 미니맵 (Step 2)**
   - 직선 가속 구간, 고속 코너, U자 헤어핀 코너, S자 복합 코너로 구성된 3D 서킷 트랙
   - 도로 양옆 빨강/하양 연석(Curb), 가드레일 방호벽 충돌 및 벽 타기 미끄러짐 물리
   - 4개 섹터 체크포인트 기반 **랩 타임(Lap Timer) / 베스트 랩 기록** 및 **실시간 2D 미니맵**

---

## 🎮 조작 방법

| 키보드 입력 | 동작 설명 |
| :--- | :--- |
| **`↑` / `↓` (또는 `W` / `S`)** | 가속(전진) / 브레이크 및 후진 |
| **`←` / `→` (또는 `A` / `D`)** | 좌·우 조향 (드리프트 중 반대 키 입력 시 **카운터 스티어링**) |
| **`Shift` + 방향키** | **드리프트 (Drift)** 시작 및 N2O 게이지 충전 |
| **드리프트 종료 직후 `↑`** | **⚡ 순간 부스터 (Instant Boost)** 발동 |
| **`Ctrl` 또는 `Space`** | 모아둔 **🔥 N2O 부스터** 아이템 사용 |
| **`R`** | 가장 가까운 트랙 중앙으로 카트 복귀 |

---

## 🚀 실행 방법

프로젝트 폴더 내의 `index.html` 파일을 더블클릭하여 웹 브라우저(Chrome, Safari, Edge 등)로 열면 즉시 플레이할 수 있습니다.
